Sumber Inspirasi — Dewa (Static)
This is a static demo for Render Static Site. Steps to deploy:
1. Push this folder to a GitHub repository.
2. On Render, choose: New -> Static Site.
3. Connect repository and set Publish directory to root (.)
4. Deploy.

This site is purposely static (no API keys required). To enable real AI or server features, convert to a Web Service and add server files.
